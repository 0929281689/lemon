# 鴻福有機檸檬園

This is the official website for 鴻福有機檸檬園 (Hongfu Organic Lemon Garden), a farm dedicated to growing organic lemons and producing related products. They are committed to environmentally friendly farming practices, avoiding pesticides and herbicides.

## Website Purpose

This website provides information about 鴻福有機檸檬園's products, including:

*   Fresh organic lemons
*   Homemade lemon vinegar

The site also includes pricing details and an online form for customers to place orders easily.

## Technologies Used

*   HTML
*   CSS
*   JavaScript
*   Bootstrap
*   Azure Static Web Apps (for deployment)
